# Scaffolding the Agogpixel Web Portal

Welcome to the inaugural devlog of Agogpixel Studio's *"Building an A- Studio in Public"* series!

In this entry, we document the architectural transformation of `agogpixel.com` from a legacy single-page static HTML file into a modern, static Astro v5 web portal.

## The Objective

Our studio needed a lightweight, high-performance web home that:
1. Showcases our debut game projects like *Escape from Cygnus X-1*.
2. Hosts transparent engineering devlogs tracking our development progress.
3. Preserves our signature branding and original CSS-based mascot rocket animation.
4. Deploys seamlessly to GitHub Pages on our custom domain `agogpixel.com`.

## Preserving the Studio Mascot Rocket

The original landing page featured a unique cosine tilt ($\pm 45^\circ$) and a 5-stage staggered thruster flame animation. Rather than abandoning this history, we encapsulated it in a modern, scoped Astro component: `<MascotRocket />`.

```astro
<div class="cosine-animation-container">
  <div class="logo"></div>
  <div class="line-scale">
    <div></div>
    <div></div>
    <div></div>
    <div></div>
    <div></div>
  </div>
</div>
```

The component supports `size` (`sm` | `md` | `lg`) and dynamic `animated` boolean flags, ensuring it can be used across hero sections, navbars, and article headers.

## The "A-" Architecture Standard

In keeping with our studio manifesto, we avoided heavy runtime JavaScript frameworks for the portal. Astro generates pure, static HTML and CSS by default, providing:
- **Instant load times**: Zero unnecessary client hydration.
- **Dark cyberpunk aesthetic**: Tailwind tokens mapped to deep space voids and neon accents.
- **Automated CI/CD**: Clean GitHub Actions workflow targeting GitHub Pages.
